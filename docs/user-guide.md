# 用户指南

## macOS

### 安装与权限

1. 使用 Xcode 构建并启动 `ClipboardManager/`。
2. 应用以菜单栏工具运行，不显示 Dock 图标。
3. 首次自动粘贴需要在“系统设置 → 隐私与安全性 → 辅助功能”授权。
4. Apple Events 权限用于备用粘贴路径，本地网络权限用于设备同步。

### 使用

- 点击菜单栏图标，或按 `⌥V` 打开剪贴板历史。
- 打开历史后可直接输入搜索；上下方向键选择条目，回车粘贴到之前的应用，Esc 先清空搜索、再关闭面板。
- 主面板采用系统原生圆角材质（macOS 26 为 Liquid Glass），置顶条目单独分组；设置和退出位于右上角「更多」菜单。
- 拖动顶部搜索栏或底部状态栏可移动面板；列表区域只用于滚动，滚动条可直接拖动。
- 点击条目会写回剪贴板并尝试粘贴到之前的前台应用。
- 搜索同时匹配内容和来源应用。
- 鼠标悬停记录时可直接置顶、翻译、同步或删除；右键菜单也支持删除等完整操作。
- 鼠标停留在条目上 350ms 后显示完整详情；移入详情可滚动和选择文本。图片显示完整预览，文件显示完整路径。
- “清空历史”保留置顶条目；设置页可以修改数量上限和保留天数。

## Windows

### 安装与权限

1. 在 Windows 主机运行 `flutter run -d windows` 或启动 Release 构建。
2. 应用启动后隐藏，按 `Alt+V` 或使用系统托盘菜单显示。
3. “开机自动启动”会写入当前用户的 `Run` 注册表项。

### 使用

- 历史页支持搜索、置顶、删除、翻译、同步和点击自动粘贴。
- 按 `Alt+V` 打开历史后，使用上下方向键选择条目，按回车将选中内容粘贴到之前的窗口。
- 鼠标停留 350ms 后出现完整内容卡片；卡片支持滚动、选择复制和手动关闭。
- Windows 当前只自动采集文本；模型保留图片与文件字段用于协议和后续扩展。
- Windows 的“清空历史”会删除全部记录，包括置顶条目；这与 macOS 保留置顶条目的行为不同。

## 隐私与翻译

- 隐私保护默认开启。密码管理器来源以及包含 `password`、`secret`、`token`、`api_key`、`private_key` 等关键词的文本不会进入历史。
- macOS 关闭历史记录期间复制的内容不会在重新开启后补录。
- macOS 将翻译 API Key 存入 Keychain；Windows 使用当前用户的 DPAPI 加密后再存储。
- 翻译会把剪贴板文本发送到用户配置的第三方接口，使用前应确认数据合规要求。
- 翻译服务会过滤推理模型返回的 `<think>...</think>` 思考过程，只显示最终结果。

## 配置加密同步

1. 两台设备连接到同一局域网。
2. 在两端同步设置中填写完全相同的 6 位数字 PIN。
3. 等待设备出现在发现列表中。
4. 在文本条目的同步操作中选择目标设备。

同步只传输文本。未配置 PIN、PIN 不一致或收到旧版明文消息时，同步会失败且不会降级为明文；发送端会提示具体原因，例如“请确认两端同步 PIN 一致”。

收到的条目出现在历史最上方，来源前带 📡 标记，一律不置顶；同一条目重复同步不会产生重复记录。

PIN 只能防止顺带看到明文，无法抵御有意监听局域网的人，不要在不可信网络中同步密码等敏感内容。

详细协议和故障排查见[同步协议](sync-protocol.md)。
